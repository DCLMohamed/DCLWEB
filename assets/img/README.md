# Image library

The image library uses one folder for each subject.

| Folder | Content |
|---|---|
| `brand/` | Current website logos and company-profile wordmarks. |
| `certifications/` | Certification marks and certificate scans. |
| `company/` | Offices, facilities, workforce, and workshop photographs. |
| `equipment/` | Compressors, dehumidification equipment, dust collectors, and forklifts. |
| `projects/` | Named project photographs from the company profile. |
| `quality/` | Quality-control and inspection photographs. |
| `services/` | Service photographs that do not identify one named project. |
| `training/` | Inspection, blasting, painting, and workforce training images. |

The website uses relative image paths in `index.html` and `quote.html`.
